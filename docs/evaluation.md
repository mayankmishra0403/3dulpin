## AI extraction pipeline
`app/services/pipeline.py`, run against the synthetic rasters:

1. **Detection** — nDSM > 2.5 m, vegetation masked (2G−R−B on ortho), binary opening (3×3),
   connected components → building footprints (bbox).
2. **Storey inference** — `round(h / 3.2)`; ≥ 7 floors → suite towers (quad-split floors,
   underground + parking + air-rights); walk-ups get floor parcels per storey.
3. **Encoding** — every detected part gets a ULPIN via the ulpin service.
4. **Evaluation** — binary mask IoU, per-building IoU matching (≥ 0.4), floor MAE.
